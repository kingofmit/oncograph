# Contributing to OncoGraph

Thank you for your interest in contributing to OncoGraph!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/oncograph.git`
3. Install dependencies: `pnpm install`
4. Build all packages: `pnpm build`

## Development

- `pnpm dev` — Watch mode
- `pnpm build` — Build all packages
- `pnpm lint` — Type-check
- `pnpm test` — Run tests
